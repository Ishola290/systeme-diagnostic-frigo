🏗️ Architecture du système

4 microservices déployés indépendamment sur Render, communiquant via API REST

🧠

Agent IA — Prédiction

Modèle ML entraîné sur des données réelles de capteurs frigorifiques. Détecte les pannes avec un score de confiance.

agent-ia-frigo-tdmm.onrender.com
⚙️

App — Orchestrateur

Reçoit les données capteurs, orchestre l'analyse IA, gère l'apprentissage continu et le simulateur de test.

frigo-app.onrender.com
🤖

GPT — Analyse LLM

GPT-4.1-mini analyse les pannes détectées et génère un rapport technique détaillé avec recommandations.

frigo-gpt.onrender.com
💬

Chat — Interface

Interface temps réel pour le technicien : alertes instantanées via WebSocket, chat avec l'IA, historique.

frigo-chat.onrender.com
